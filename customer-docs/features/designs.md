# Designs (Design Studio)

> **Status:** PUBLISHED
> **Last updated:** 2026-04-26
> **Applies to:** All plans

## What it does

Design Studio is an in-browser editor for social posts, banners, and thumbnails. Pick a template or start blank, drag assets from your library, edit text, then export PNG/JPEG/PDF/MP4.

## When to use it

- Producing on-brand creative without leaving img-man.
- Reusing an asset (logo, photo, palette) across many designs.
- Quick edits to existing designs without re-importing.

## Step-by-step

### Create

1. Open **Designs** in the sidebar.
2. Click **New design** → pick a size (Instagram, story, banner, custom).
3. The editor opens with an empty canvas.

### Add content

- **Library tab** — drag any asset from your img-man library onto the canvas.
- **Text** — pick a heading, body, or your saved brand styles.
- **Shapes / Icons** — basic shapes plus an icon search.
- **Upload** — drop a one-off file straight onto the canvas.

### Edit

- Drag handles to resize; hold Shift to constrain proportions.
- Use the right panel for color, opacity, filters, shadow, blend mode.
- Multi-select with Shift-click; group with Ctrl/Cmd-G.

### Export

Click **Export** → choose format (PNG / JPEG / WebP / PDF / MP4 for animations) and resolution. The export becomes a new asset in your library, so you can copy a [public URL](public-asset-url.md) immediately.

## Tips & limits

- Saves are continuous; you don't need a Save button.
- Version history is kept for 30 days (Pro: 1 year).
- Max canvas size is 8000×8000 px.

## Troubleshooting

| Problem | Cause | Fix |
| --- | --- | --- |
| Editor won't load | Browser blocking third-party storage. | Allow storage for the img-man domain. |
| Library tab empty | Permission scope on the user. | Ask an admin to grant `read` access. |
| Export pixelated | Canvas resolution too low. | Raise canvas size before export. |
